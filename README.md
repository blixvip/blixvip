## ⭐ Main project: [BLIX](https://blixvip.com)

<a href="https://blixvip.com"><img src="assets/blix-hero.jpg" width="100%" alt="BLIX: AI-powered Solana memecoin terminal"></a>

**[BLIX](https://blixvip.com) is an AI-powered memecoin terminal for Solana.** Every pump.fun launch live, AI coin ratings, narrative tracking, wallet and X tracking, and one-click trading, all on one screen. Trade real SOL or practise in paper mode first.

**[Start trading at blixvip.com →](https://blixvip.com)** &nbsp;·&nbsp; [Public API](https://blixvip.com/api) &nbsp;·&nbsp; [MCP server](https://blixvip.com/mcp) &nbsp;·&nbsp; [Source](https://github.com/blixvip/blixtrade)

## 🆕 New: [GenMotion](https://github.com/blixvip/GenMotion)

<a href="https://github.com/blixvip/GenMotion"><img src="https://raw.githubusercontent.com/blixvip/GenMotion/main/docs/demo.gif" width="100%" alt="GenMotion demo film, made in GenMotion"></a>

**Type an idea, get a finished motion-graphics video.** GenMotion writes the storyboard, paints every scene with the image model you pick (17 of them: GPT Image, Nano Banana, FLUX, Imagen, plus the top Chinese models Seedream, Qwen-Image, Kling, Wan, Hunyuan and more), animates kinetic type over it and exports a 1080p MP4. Bring your own API keys; zero dependencies.

**[Get GenMotion →](https://github.com/blixvip/GenMotion)** &nbsp;·&nbsp; [v1.0 release](https://github.com/blixvip/GenMotion/releases/tag/v1.0.0)

## About

I'm Kaihan Wasely. I build local-first tools for video work — things that run on
your own machine, with no server to sign into, no API keys to paste, and no usage
meter. Where a tool needs a model, it borrows the Codex or Claude Code login you
already have rather than asking for a new one.

The constraint I keep coming back to is that a creative tool should work offline
and leave its output in a format you can edit by hand afterwards. So the video
projects compile to plain HTML and CSS instead of a binary timeline, the editors
write files you can open in a text editor, and nothing phones home. Mostly Python
and TypeScript, with ffmpeg doing the heavy lifting.
